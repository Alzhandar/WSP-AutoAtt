# 🤖 SeniorAtt-Bot - Professional Telegram Bot

Профессиональный Telegram бот для управления системой автоматической отметки посещаемости КБТУ.

## 🚀 Возможности

### ✨ Основной функционал:
- 📊 **Мониторинг статуса** в реальном времени
- 🚀 **Запуск/остановка** attendance bot
- 📅 **Проверка расписания** 
- ⚙️ **Гибкие настройки** пользователя

### 🔔 Умные уведомления:
- 🎯 Уведомление о появлении новых предметов для отметки
- ✅ Подтверждение успешной отметки посещения  
- ❌ Оповещения об ошибках в работе системы
- 📱 Мгновенные push-уведомления

### 🛡️ Безопасность:
- 🔐 Автоматическое удаление паролей из чата
- 👤 Персональные настройки для каждого пользователя
- 🔒 Защищенное хранение учетных данных

## 📋 Установка и запуск

### 1️⃣ Предварительные требования:
- Python 3.8+
- Рабочий Docker с attendance bot
- Токен Telegram бота

### 2️⃣ Быстрый запуск:
```bash
# Клонировать проект (если еще не сделано)
cd WSP-AutoAtt

# Запустить Telegram бота
./start_telegram_bot.sh
```

### 3️⃣ Ручная установка:
```bash
# Установить зависимости
pip3 install -r telegram_requirements.txt

# Запустить бота
python3 telegram_bot.py
```

## 🎯 Настройка бота

### Получение токена:
1. Найдите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Получите токен и добавьте в код

### Конфигурация:
```python
TELEGRAM_TOKEN = "YOUR_BOT_TOKEN_HERE"
ATTENDANCE_API_URL = "http://localhost:8000"  # URL вашего attendance bot
```

## 📱 Использование

### Команды:
- `/start` - 🏠 Главное меню
- `/status` - 📊 Быстрый статус  
- `/help` - ℹ️ Справка
- `/setlogin` - 👤 Установить логин КБТУ
- `/setpassword` - 🔑 Установить пароль

### Интерактивное меню:
- 📊 **Статус** - Проверка состояния attendance bot
- 🚀 **Запустить** - Активация мониторинга
- ⏹️ **Остановить** - Деактивация бота  
- 📅 **Расписание** - Просмотр расписания
- ⚙️ **Настройки** - Конфигурация аккаунта

## 🔧 API Endpoints

Telegram бот взаимодействует с основным attendance bot через REST API:

- `GET /status` - Статус бота
- `GET /attend` - Запуск мониторинга  
- `GET /stop` - Остановка бота
- `GET /check-page` - Проверка расписания
- `GET /notifications` - Получение уведомлений

## 📊 Мониторинг и уведомления

### Типы уведомлений:
1. **🎯 Subjects Available** - Найдены предметы для отметки
2. **✅ Attendance Marked** - Посещение отмечено успешно
3. **❌ Error Alert** - Ошибка в работе системы
4. **🔄 Status Update** - Периодические обновления статуса

### Настройка уведомлений:
- Включение/отключение через меню настроек
- Автоматическая отправка при изменении статуса
- Умная фильтрация повторных уведомлений

## 🐛 Устранение неполадок

### Частые проблемы:

1. **Бот не отвечает**
   - Проверьте токен
   - Убедитесь что процесс запущен

2. **Ошибки API**
   - Проверьте работу Docker контейнера
   - Убедитесь что порт 8000 доступен

3. **Нет уведомлений**
   - Проверьте настройки уведомлений
   - Убедитесь что attendance bot работает

### Логи и диагностика:
```bash
# Проверка статуса Docker
docker-compose ps

# Логи attendance bot  
docker-compose logs

# Логи Telegram бота

```
